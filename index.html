Code Review

Code review is a review process of code by your peers. It is where others review your code to help identify flaws, bugs, edge cases or any other problems that may create issues after the product is released (GitLab, n.d.).

This is an important process because it aids in identifying potential issues that you may not have seen. When I finish an application or an enhancement to an existing application, when I test myself, I know how the process should work. So, it can be difficult to find ways to break my own program. Where others would be able to spot because they are reviewing the code objectively. Without the process, the potential for bad programs to escape increases.

Enhancement One: Software Design/Engineering

This Artifact is an Android Application that can run on a phone running Android. It is an application that utilizes a phone built in light sensor to display the current ambient light value in Lux (illuminance).
It displays the current value, the maximum, minimum and average values. This was initially created In February of 2026

>> Screen capture of final enhancement

I chose to include this artifact because it displays competence in developing a phone app utilizing build in sensor functions. The use of one sensor gives an understanding of the SensorEventListener and its methods and how they work to create working apps using real time data. Using the data to show the min. max and average displays some practical use of the tools given. The artifact was improved by cleaning errors, adding comments to code blocks that were missing comments and adding functionality on the sensorUpdate method.

The enhancement process allowed me to take more of a design approach since most of the code base was complete. While there were improvements made to the code, the heavier lifting was in the UI/UX. There was a learning curve jumping back into Android Studio. Once I got my bearings, I was able to make the updates and enhancements. The biggest improvement with this app is how the lux is displayed. Giving the user a Max, Min and average brightness. I also added a small game that users can walk around and find the hidden lux value. You get a too high of too low message to help assist in finding that sweet spot.

# Using paramarized queries 
class ClientRecordHelper:
    
    def __init__(self, database):
        self.db = database

    # Get all the clients from the database 
    def get_all_clients(self):
        cursor =  self.get_cursor()
        select_q = "SELECT * FROM clients"
        cursor.execute(select_q)
        return cursor.fetchall()

    # Gets all the services available 
    def get_all_services(self):
        cursor =  self.get_cursor()
        select_q = "SELECT * FROM services"
        cursor.execute(select_q)    
        return cursor.fetchall()

    # Lookup a client from the client ID
    def get_client_by_id(self, id:int):
        cursor = self.get_cursor() 
        select_q = "SELECT * FROM clients WHERE client_id = %s"
        cursor.execute(select_q, (id,))
        return cursor.fetchone()

    # Get the service description from the ID
    def get_service_desc(self, id:int):
        cursor = self.get_cursor() 
        select_q = "SELECT service_name FROM services WHERE service_id = %s"
        cursor.execute(select_q, (id,))
        return cursor.fetchone()

    # Update a clients service choice
    def update_client_service(self, id:int, service_id:int):
        cursor = self.get_cursor()
        update_q = "UPDATE clients SET service_choice = %s WHERE client_id = %s"
        cursor.execute(update_q, (service_id,id))
        return cursor.rowcount

    # Add a client 
    def add_client(self, user_data:dict):
        cursor = self.get_cursor()
        # using parameterized queries
        insert_q = "INSERT INTO clients (first_name, last_name, phone) VALUES (%s, %s, %s)"
        cursor.execute(insert_q, user_data)
        self.db.get_connection().commit()
        return cursor.rowcount

    # Add a user for the application
    def add_user(self, username:str, password_hash:str):
        cursor = self.get_cursor()
        
        # See if the username exists
        select_q = "SELECT COUNT(*) FROM users WHERE username = %s"
        cursor.execute(select_q, (username,))
        count = cursor.fetchone()

        # If there are any results don't try to add the user
        if (count[0] == 0):
            insert_q = "INSERT INTO users (username, password_hash) VALUES (%s, %s)"
            cursor.execute(insert_q, (username,password_hash))
            self.db.get_connection().commit()
            return cursor.rowcount
        else:
            return "User alrady exists"

    # Get the password hash to verify against entered password
    def get_username_and_password_hash(self, username:str):
        cursor = self.get_cursor()
        select_q = "SELECT password_hash FROM users WHERE username = %s"
        cursor.execute(select_q, (username,))
        record = cursor.fetchone()

        # returns the record 
        if record is not None:
            return record
        else:
            return

    # Returns true if the user exists
    def username_exists(self, username:str):
        cursor = self.get_cursor()
        select_q = "SELECT COUNT(*) FROM users WHERE username = %s"
        cursor.execute(select_q, (username,))
        record = cursor.fetchone()
        if record[0] > 0:
            return True
        else:
            return False

    # Removes a client 
    def remove_client_by_id(self, id:int):
        cursor = self.get_cursor()
        delete_q = "DELETE FROM clients where client_id = %s"
        cursor.execute(delete_q, (id,))
        self.db.get_connection().commit()
        return cursor.rowcount

    # Gets a cursor
    def get_cursor(self):
            connection = self.db.get_connection()
            return connection.cursor()

    # Prints the clients in a clean format
    def print_clean(self, record:list):
        
        for elem in record:
            service_name = self.get_service_desc(elem[4])[0]
            print("".ljust(50,"*"))
            print(f"Client ID: {elem[0]}")
            print(f"Name: {elem[1]} {elem[2]}")
